# tendant — mobile

Flutter client for tendant.

## Run

```sh
flutter pub get
flutter run            # device or simulator
flutter test           # widget tests
```

## CI

No mobile CI workflow is generated by `scaffold` — signing, store config, and the build matrix are project-specific. Add `.github/workflows/mobile.yml` when ready.

Common starting points:
- iOS: `flutter build ipa --export-options-plist=...`
- Android: `flutter build appbundle --release`
